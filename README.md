# Band Song Randomizer

A gloriously 8-bit, no-repeat song picker for band rehearsal.

**Live site:** https://band-song-randomizer.jjason123.chatgpt.site

## What it does

- Picks one random song from the current rehearsal pool
- Removes each selected song until the cycle is reset
- Saves edits to the song library in the browser's local storage
- Adds and removes songs through the built-in song editor
- Displays each selection with an animated 8-bit reveal
- Works on desktop, Chromebook, tablet, and phone

## Run locally

Open `dist/index.html` in a modern web browser. No installation or build step is required.

## Data and privacy

The song library stays in the browser on the device where it was edited. The app has no account system and sends no song data to a server.
